# Unique Culinary Dragons item art

This directory contains the original pixel-art generator used for Culinary Dragons item textures.

The art was redesigned from public visual references only:

- Farmer's Delight public item/crop presentation: https://github.com/vectorwing/FarmersDelight/tree/1.18.2
- Farmer's Delight license: MIT
- Let's Do Vinery public gallery: https://modrinth.com/mod/lets-do-vinery/gallery

No Farmer's Delight or Vinery source code, textures, models, branding, or individual assets are copied into Culinary Dragons. The generator creates original 16x16 PNGs with separate silhouette families for fruits, juice bottles, smoothie cups, fermented bottles, mugs, bowls, and plated foods.

Run from the project root:

```bash
python3 tools/generate_unique_item_art.py
```
